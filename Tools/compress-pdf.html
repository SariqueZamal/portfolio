❓ Frequently Asked Questions

💡 How does client-side PDF compression reduce file size?

Our compression engine extracts page object streams, simplifies vector geometries, removes duplicate metadata, and downsamples raster imagery to web-optimized DPI standards, resulting in significant file size savings while preserving document readability.

💡 Are my documents ever uploaded to an external server?

No. The entire compression routine executes purely inside your device's browser memory sandbox. Zero bytes are uploaded to remote servers or third-party cloud infrastructure.

💡 Will text readability or searchable vectors be degraded?

Text streams remain completely crisp and searchable. Only heavy high-resolution embedded photographs and scanned graphics are downsampled according to your chosen compression preset.

💡 Is there a file size limit on compression?

There are no arbitrary server rate limits. The maximum PDF size depends strictly on your computer or mobile device's available browser memory (RAM).

💡 Can I compress password-protected PDF files?

You must decrypt password-protected PDF files first before compressing page object streams.
